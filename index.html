🎯 任务目标

⚠️ 四种判断结果

✓ 击中 (Hit) - 行李中有违禁品，你正确按下"报警"

✗ 漏报 (Miss) - 行李中有违禁品，你错误按下"放行"

! 虚报 (False Alarm) - 行李中无违禁品，你错误按下"报警"

✓ 正确拒绝 (Correct Rejection) - 行李中无违禁品，你正确按下"放行"

📊 指标解读

d' (敏感性): 值越大表示你区分违禁品和普通行李的能力越强。d' = 0 表示随机猜测。

c (判断标准): 反映你的反应倾向。c < 0 表示宽松标准（容易报警），c > 0 表示严格标准（谨慎报警），c ≈ 0 表示中性标准。

可视化分析

ROC 曲线 (受试者操作特性曲线)

ROC曲线展示了在不同判断标准下虚报率(P(FA))与击中率(P(Hit))的关系。曲线上的绿点表示你的实际工作点。曲线越靠近左上角，说明敏感性越高。

双正态分布模型

展示了噪音(N, 蓝色)和信号(S, 红色)的强度分布。两条曲线之间的距离为 d'，橙色虚线表示你的判断标准 c。当 c 靠近左侧时，表示你更容易报警（宽松标准）。
