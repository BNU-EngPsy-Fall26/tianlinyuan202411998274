# 信号检测论(SDT)交互式实验 - 机场安检场景

## 📋 项目简介

本项目是一个基于信号检测论(Signal Detection Theory, SDT)的交互式心理物理学实验网站，采用**机场安检X光行李检测**作为实验场景。通过模拟真实的工作情境，让被试体验并理解信号检测的核心概念：**敏感性(d')** 和 **判断标准(c)**。

**适用课程**: 工程心理学 / 认知心理学 期末大作业
**开发语言**: 纯前端 HTML5 + CSS3 + JavaScript (ES6+)
**运行方式**: 双击 `index.html` 即可在浏览器中完美运行

## 🎯 实验场景设计

### 核心概念映射

| SDT术语 | 机场安检场景 |
|---------|------------|
| **信号 (Signal)** | 行李中包含违禁品（如刀具） |
| **噪音 (Noise)** | 行李中只有普通物品（衣物、水杯、电子产品等） |
| **先验概率 P(S)** | 违禁品出现的概率（可配置 10% - 90%） |
| **判断标准** | 安检员决定"报警"的严格程度 |
| **敏感性 d'** | 安检员区分违禁品和普通物品的能力 |

### 四种判断结果

1. **✓ 击中 (Hit)**
   - 实际：行李中有违禁品
   - 判断：按下"报警"
   - 意义：正确识别威胁

2. **✗ 漏报 (Miss)**
   - 实际：行李中有违禁品
   - 判断：按下"放行"
   - 意义：漏掉威胁（危险！）

3. **! 虚报 (False Alarm, FA)**
   - 实际：行李中无违禁品
   - 判断：按下"报警"
   - 意义：误判普通物品为威胁（浪费时间）

4. **✓ 正确拒绝 (Correct Rejection, CR)**
   - 实际：行李中无违禁品
   - 判断：按下"放行"
   - 意义：正确放行

## ⚙️ 实验参数设置

### 1. 总试次数量
- **范围**: 20 - 100 次
- **默认**: 30 次
- **建议**: ≥30 次以获得稳定的统计结果

### 2. 先验概率 P(S)
- **范围**: 0.10 - 0.90
- **默认**: 0.50
- **说明**: 每轮实验中违禁品出现的比例。较低的 P(S) 会鼓励被试采用更严格的判断标准。

### 3. 刺激呈现时间
- **选项**: 500ms / 1000ms / 2000ms / 无限制
- **默认**: 1000ms
- **说明**: X光图像显示的时间。时间越短，任务难度越大。

### 4. 难度调节 (d')
- **范围**: 20% - 100%
- **默认**: 50%
- **实现方式**: 改变Canvas绘制刀具时的透明度
- **说明**:
  - 20% = 刀具非常模糊（困难）
  - 100% = 刀具非常清晰（简单）
  - 实际物理 d' 与透明度呈非线性关系

## 📊 实验结果指标

### 基础指标

| 指标 | 计算公式 | 说明 |
|------|---------|------|
| **击中率 P(Hit)** | Hit / (Hit + Miss) | 有违禁品时报警的比例 |
| **虚报率 P(FA)** | FA / (FA + CR) | 无违禁品时报警的比例 |
| **准确率 Accuracy** | (Hit + CR) / Total | 整体判断正确率 |

### SDT 核心指标

#### 1. 敏感性 d' (d-prime)

**公式**:
```
d' = Z(P(Hit)) - Z(P(FA))
```

**含义**:
- 衡量被试区分信号和噪音的能力
- **d' > 0**: 被试具有辨别能力
- **d' = 0**: 被试无法区分信号和噪音（随机猜测）
- **d' 越大**: 敏感性越高

**实现**: 使用标准正态分布的逆累积分布函数（Inverse Normal CDF）计算 Z 分数

#### 2. 判断标准 c (criterion)

**公式**:
```
c = -0.5 × (Z(P(Hit)) + Z(P(FA)))
```

**含义**:
- 衡量被试的反应倾向（决策严格程度）
- **c < 0**: 宽松标准（容易报警，宁愿错杀也不放过）
- **c = 0**: 中性标准
- **c > 0**: 严格标准（谨慎报警，避免误判）

## 🔧 技术实现

### 核心技术栈

- **HTML5 Canvas**: 动态绘制X光图像、噪音背景、刀具信号
- **CSS3**: 暗黑科技风UI设计，扫描线动画效果
- **JavaScript ES6+**: 模块化设计，面向对象编程
- **Chart.js**: ROC曲线和正态分布图可视化

### Canvas 绘图逻辑

#### 噪音 (Noise) 生成
```javascript
1. 黑色背景 + 网格线（模拟X光扫描）
2. 随机噪点（2000+个像素点）
3. 随机几何图形（圆形、矩形、三角形）
4. 随机颜色和透明度
```

#### 信号 (Signal) 生成
```javascript
1. 在噪音基础上叠加刀具
2. 刀具由刀身、刀尖、刀柄三部分组成
3. 添加高光效果增强真实感
4. 透明度由难度参数控制（0.3-1.0）
```

### SDT 数学计算 (`js/math-sdt.js`)

#### 1. 标准正态分布 CDF
使用 Abramowitz and Stegun 近似公式计算累积概率:
```
Φ(z) = 0.5 × (1 + erf(z/√2))
```

#### 2. 逆正态分布 CDF (Z-score计算)
使用 Peter J. Acklam (2003) 的 rational approximation 算法:
- 高精度区域 (0.02425 < p < 0.97575): 直接多项式近似
- 低精度区域: 分位数变换 + 多项式近似

#### 3. 边缘校正
当 P(Hit) 或 P(FA) 为 0 或 1 时，采用 1/(2N) 校正:
```javascript
adjustedP = (count === 0) ? 1/(2N) : (count === N) ? 1 - 1/(2N) : p
```

d' = Z(P(Hit)) - Z(P(FA))

## 🎓 教学应用建议

### 演示步骤

1. **参数设置演示**
   - 设置 P(S) = 0.5, 试次 = 20, 难度 = 50%
   - 运行一次实验

2. **概念讲解**
   - 展示 ROC 曲线和双正态分布图
   - 解释 d' 和 c 的含义

3. **参数变化实验**
   - **任务1**: 固定 d'，改变 P(S)（如 0.2 vs 0.8），观察 c 的变化
   - **任务2**: 固定 P(S)，改变难度（透明度），观察 d' 的变化

4. **个体差异分析**
   - 让多名被试完成实验
   - 比较不同个体的 d' 和 c 值

### 讨论问题

1. 为什么 P(S) 会影响判断标准 c？
2. 在实际安检中，如何平衡漏报和虚报的代价？
3. 如果你是一名机场安检员，你会选择什么样的判断标准？
