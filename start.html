🚀 信号检测论实验

欢迎使用信号检测论(SDT)交互式实验系统！请选择以下方式之一开始实验。

直接开始实验

📋 运行方式说明

方法一（推荐）: 直接点击上方"直接开始实验"按钮，或直接在文件管理器中双击 index.html

方法二: 使用本地服务器（适合开发和调试）

# Python 3
python -m http.server 8000

# 然后访问 http://localhost:8000

🎯 实验内容

在本实验中，你将扮演机场安检员，判断X光扫描图像中是否包含违禁品（刀具）。

系统将自动记录你的判断结果，并计算：

  • ✓ 击中率 (Hit Rate)
  • ⚠️ 虚报率 (False Alarm Rate)
  • 📊 敏感性 d'
  • ⚖️ 判断标准 c
